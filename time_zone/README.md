# Time Zone Converter — Enhanced Task 4

## Added features
- Sign In / Create Account screen
- Local profile name and email
- Profile picture from phone gallery
- Dark mode + light mode toggle
- User profile bottom sheet
- Sign out
- Favorite conversion saved locally
- Current time button
- Date/time picker
- Worldwide city search
- Swap FROM/TO
- Automatic timezone and daylight-saving handling
- Black + sea/ocean visual theme

## Setup
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Terminal:
   flutter create .
   flutter pub get
   flutter run

## APK
flutter build apk --release

APK:
build/app/outputs/flutter-apk/app-release.apk

### Note
Authentication is a local demo authentication flow suitable for an internship UI/project. It does not connect to a real server or Firebase.
