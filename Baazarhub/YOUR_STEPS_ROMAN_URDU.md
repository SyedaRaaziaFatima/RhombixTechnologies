# Husnain ko kya karna hai

Project ka code, design, demo data, database schema aur security policies pehle
se tayyar hain. Aap ko sirf ye kaam karne hain:

## Abhi demo check karne ke liye

1. `bazaarhub` folder extract karein.
2. Phone mein Developer Options aur USB Debugging on karke cable se connect karein.
3. `setup_and_run_demo.bat` par double-click karein.
4. App mein pre-filled email/password se login karein.

## Real online data ke liye

1. Supabase par free account aur naya project banayein.
2. Dashboard ke SQL Editor mein `supabase/schema.sql` ka complete code run karein.
3. Project URL aur **public anon/publishable key** copy karein.
4. `run_with_supabase.bat` open karke dono values paste karein.

Service-role key kisi ko na bhejein aur app mein kabhi add na karein. Agar kisi
step par error aaye to sirf us error ka screenshot share karein.
